# LineEcho - Distribuição Oficial & Atualizações OTA

Repositório oficial para distribuição de binários (APKs) e atualizações automáticas (OTA) do aplicativo LineEcho.

## Downloads
Os arquivos de instalação (.apk) estão disponíveis na aba [Releases](https://github.com/MarlonMVieira/LineEcho/releases).

- **Modelo Root (`LineEcho.apk`)**: Versão com suporte a comandos avançados e controle de sistema.
- **Modelo Lite (`LineEcho_Lite.apk`)**: Versão para qualquer dispositivo Android sem necessidade de root.

## Atualizações Automáticas (OTA)
O aplicativo consulta automaticamente o arquivo `update.json` hospedado nas Releases para verificar e baixar novas versões.
